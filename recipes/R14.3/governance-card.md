# Governance card: R14.3 Chase overdue actions and carry them into the next agenda

Northstar's filled card from the book.
Northstar is fictional; copy the structure, not the entries.

Owner: Tom Rivera; review date: annual library review (Chapter 18).

| Field | Entry |
|---|---|
| Data class | Internal: task titles, owners and dates. Hosting: Northstar's Power Platform environment, in its Microsoft 365 tenant's region. No AI |
| Approver | The chair decides each carried item; Tom approved the workflow and reminder text |
| Access | `svc-meeting-chase`: read tasks, register, calendars, agenda decisions; write tracking list and agenda; message owners; no task rights |
| Logging | Reminders, agenda entries, date changes and the weekly count, by series only: 13 months |
| Kill switch | Owen or the IT engineer turns it off; Tom sets the stop flag (Chapter 3). "Pending" keys wait for Owen; chairs check the task plan |
