# Google Workspace Studio

Checked 2026-10-12.

| Item | As of October 2026 |
|---|---|
| What it is | Google's automation for Workspace (formerly Workspace Flows), generally available since 2025-12-03 and included in Workspace business plans |
| Limits | 25 flows a user and 20 steps a flow; a daily run limit exists, but no number is stated |
| AI usage | Counts against Workspace AI usage limits, set per user by edition; Google scheduled enforcement from 2026-11-01 |
| Extending it | Custom steps, webhooks and beta third-party connectors since September 2026 |
| Export | No user export file; admins export flow configurations and execution logs with the Data Export tool; users share flows as an in-organization copy link |

Because there is no export format, a Workspace Studio build lives in the recipe's `build-spec.md` alone.
Use it as Starter-band suite automation for jobs inside Workspace, and check the usage limits after enforcement starts.
