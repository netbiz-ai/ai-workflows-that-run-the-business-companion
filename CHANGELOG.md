# Changelog

Generated by `tools/changelog.py` from `changes/` and each recipe's golden set and test report; do not edit by hand.
Every change that affects a recipe is here, dated, newest first.

## 2026-10-20: phase 2 n8n builds

- Added a tested n8n build for every recipe: `recipes/<ID>/n8n/workflow.json`, generated by `tools/builds/` and run against the recipe's golden set on n8n 2.42.7 (self-hosted) with the mock systems in `tools/mock-systems/`; each run's result is in `n8n/test-report.md`, and the AI cases ran on Claude Haiku 5.5.
- Every workflow has the book's stop flag (Chapter 3) after its Config node; an unreadable stop list stops the run with an exception-queue row.
- Added `patterns/duplicate-check/schema.sql`: the key log, decision log and exception queue as Postgres tables, with a key column that refuses a second copy in the same step.
- Extended the golden sets with the failure paths each recipe's failure table names, an AI-error case for every AI recipe, and a "Stop flag" case; each extension is a row ending "(companion extension)" (see "Recipe status" below).
- Refuse rows whose bad output a well-behaved model will not produce are now tested with that exact output injected, and each is paired with a live-model row showing the model refuses.
- R7.1 returns each invoice line as description, quantity, unit price and amount (the book prints amounts only) so that R7.2 can pair lines; see the note in `recipes/R7.1/build-spec.md`.
- Prompt changes found by running the golden sets on the live model: R4.3 (write GAP without brackets), R5.2 (claim and criterion shapes), R5.3 (no numbered lines), R6.2 (never-say phrases passed with the input), R7.4 (no worked-out numbers), R9.2 (when a question is about the asker), R10.1 to R10.3 (mask token passed with the input), R12.2 (sentence and number shape), R15.1 (rules apply to subject lines; scan words; use each listed claim), R15.1 list-claims (each claim carries its type).
- Every prompt's output schema is now sent with its instructions, and AI calls allow 4,096 tokens, because Claude Haiku 5.5 thinks before it answers and a low cap stopped replies before any JSON.
